# trk-PWA

trk! を **PWA として配布する**ためのリポジトリ（準備中）。

- 現在地：**空**。アプリ本体はまだ入っていません。
- 土台の候補：上流 `trk` の **1.1.8（trk219）**＋`trk-apk` のモバイル画面シェル。
- 配布の第一候補：**HTTPS（GitHub Pages）＋ iPhoneの「ホーム画面に追加」**。

## 読む順番

1. [iPhone向け配布のブレインストーミング](docs/IPHONE-PWA-BRAINSTORM-2026-10-30.md) — 手段の比較、iOSの制約、土台の選び方、ロードマップ、実機チェックリスト。
2. [iOS診断ページ](tools/ios-probe.html) — Pages公開後にiPhoneで開くと、その端末のPWA・保存・取込・音の対応状況を確認できます（アプリの一部ではありません）。

## このリポジトリの原則（案）

- **上流を捨てない**：`trk` の更新にマージで追従できる形を保つ。
- **Android固有を持ち込まない**：Capacitor・`apk-native.js` などはPWAには入れない。
- **未確認を合格にしない**：ビルドが通ったことと、iPhone実機で動いたことを区別して記録する。
- **利用者データを最優先**：URL・保存領域・バックアップの説明を後回しにしない。
