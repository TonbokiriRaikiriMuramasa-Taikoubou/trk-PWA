## 1. 準備

1. Drive の手渡しフォルダから `trk-standalone-2026-10-31-trk225.zip` を落とし、**新しいフォルダ**へ展開する（前回の trk224 のフォルダに重ねない）。落としたら、同じフォルダの `README-まず読む-2026-10-31-trk225.txt` に書いた `sha256` と照合する（`sha256sum <ファイル>`／macOS は `shasum -a 256`／Windows は `certutil -hashfile <ファイル> SHA256`）。
2. `index.html` を開く。オフラインも試すなら、展開したフォルダで `python3 -m http.server 8000` を実行して `http://127.0.0.1:8000/` を開く（Service Worker は `file://` では動きません）。
3. 記録は「§番号・端末・OS・ブラウザ・拡大率・スキン名」で。例：`2-2 × / Pixel 8 / Android 15 / Chrome 141 / 125% / shadow`。

> 保存データは開き方ごとに別です。`file://` と `http://127.0.0.1:8000/` と公開URLは、それぞれ別の保存場所になります。

## 2. まず見てほしい4点（今回の修正の中心）

### 2-1 ① スマホ型の「エフェクト」のタブに ▶ TV が出るか

**手順**：右上の 📱／🖥 でスマホ型にする → 下のナビで「エフェクト」→ 下のほうまでスクロール。

- [ ] **▶ TV** が見える（trk222 では、ここが空いていた）
- [ ] 🎛 エフェクト・▶ TV のあいだの**間隔が詰まっていない**（欄のあいだは 14px）
- [ ] 「くわし（EQ・スキン・メニュー）」「くわし（設定と映像の確認）」・TRKアンプ・TRKエフェクト・TRK MIDI MIX が並ぶ
- [ ] ▶ TV を押すと、TV（映像の窓）が**画面の上に重なって**開く
- [ ] 「ライブラリ」のタブへ戻ると、▶ TV は消えている（設定「エフェクトの欄をライブラリにも出す」を**オン**にすると出る）
- [ ] エフェクト ⇄ ライブラリを**4往復**しても、欄が二重にならない・消えたままにならない

### 2-2 ② 拡大率 125% で、カードの下端が再生バーに隠れないか

**手順**：⚙ → 🖥 画面と再生バー → 拡大率を **125%** に（PC型のまま）。選曲画面（曲リスト）を下までスクロール。

- [ ] カードの**下端がバーの裏に入らない**（バーの上で切れて、カードの中はスクロールできる）
- [ ] 100%・75%・50% でも同じ（50% は前回「余りすぎ」でしたが、今回は**バーのすぐ上**まで使う）
- [ ] **125% → 100% に戻すと**、余白も 100% の値に戻る（前回は 118px のまま残った）
- [ ] ウィンドウの大きさを変えても（最大化 → 縮める）、カードとバーが重ならない
- [ ] スマホ型でも、カードの下にバーの高さぶんの余白がある

**期待している数値**（1440×900・バーが実寸 60px のとき。参考）：

| 拡大率 | ステージの設計の高さ | カードの下端 | バーの上端 |
| --- | --- | --- | --- |
| 50% | 2160px | 738.8px | 750px |
| 75% | 1440px | 732.9px | 750px |
| 100% | 1080px | 727.5px | 750px |
| 125% | 864px | 721.9px | 750px |

### 2-3 ⑥ 拡大率を変えても、背景の映像と MMD/VRM が画面に合うか

**手順**：PC型で拡大率を **50%** にし、背景の映像（▶ TV か映像つきの曲）と、MMD／VRM のキャラ（設定で切り替え）を出す。

- [ ] 背景の映像・エフェクトが**画面いっぱい**に描かれる（50% で左上 1/4 だけ、になっていない）
- [ ] MMD／VRM のキャラが**決まった位置**に出る（50% で左上へ寄ったり、125% で右下へはみ出したりしない）
- [ ] 100% では今までと同じ見え方
- [ ] ゲーム中は拡大率が 100% に戻り、盤面が欠けない

### 2-4 ⑦ ようこそ（初回の案内）を閉じたあと、下の再生バーが出るか

**手順**：初回の状態（`?reset=all` のあと、または設定の「ようこそをもう一度」）で、案内を ✕ で閉じる。

- [ ] 閉じた**すぐ**に、下の再生バーが出る（前回は、開き直すまで出なかった）
- [ ] 案内を閉じたあと、設定の窓・プレイリスト・インストール案内を開いて閉じても、バーが戻る
- [ ] バーが出ているあいだ、🛟 浮きボタン・通知（トースト）と重ならない

## 4. ④⑤ は `/trk/` へ移したあとに

この2つは「同じオリジンに2つの trk! がある」ことが前提なので、**移設のあと**に確認します。手順だけ先に置きます。

- [ ] **④ キャッシュの持ち主**：`/trk-PWA/` と `/trk/` を両方開き、DevTools → Application → Cache Storage に `…@trk-pwa` と `…@trk` が**別々に**ある。片方を更新（再読み込み）しても、もう片方のキャッシュが消えない
- [ ] **⑤ 設定の保存**：`/trk-PWA/`（古い版）で何か設定を変えて保存 → `/trk/`（新しい版）を開いて、**拡大率・画面の形が残っている**（前回は、古い版の保存で消えました）
- [ ] 工場出荷（`?reset=all`）では、知らないキーも含めて初期化される（初期化の意味は変えていません）

## 7. 用語

| 言葉 | 意味 |
| --- | --- |
| PC型／スマホ型 | 同じアプリの2つの画面構成。スマホ型＝下部ナビで1画面1役割 |
| 拡大率 | 文字とボタンの大きさ（50／75／100／125%）。ステージ全体を縮めて描くので、はみ出しません |
| ステージ | アプリの 1920×1080 の画面。拡大率に合わせて設計サイズが変わります |
| スコープ | 公開している場所（`/trk-PWA/` や `/trk/`）。キャッシュと設定は、この単位で分けています |
| バーの設計の高さ | 再生バーの高さを、ステージの座標に直した値（`--trk-playerbar-stage-h`） |
