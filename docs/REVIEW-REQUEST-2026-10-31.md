## 4. 既知の制約・やらないこと

- **実ブラウザの自動テストはありません**：`npm run check` は Node と jsdom で動きます。実ブラウザのスモーク（`tools/smoke-browser.mjs`）は外部の Chrome を指定したときだけ動きます。
- **この作業環境にブラウザと端末がない**ため、見た目の最終確認はできていません（§2 がその代わりです）。
- **`zoom` のブラウザ差**：効かない環境では再生バーが拡大されないだけで、機能は落ちません。
- **エフェクト欄は CSS で見せ分け**ています。DOM を移す方法は `tv-dock.js`・`fx-dock.js` の MutationObserver と取り合うため採っていません。
- **新しい保存キーは増やしていません**（`core.settings` の中だけ）。移行（[`MIGRATIONS.md`](MIGRATIONS.md)）も不要です。
- **配布ZIPは作りません**（このリポジトリは GitHub Pages で配ります。[`HANDOFF.md`](HANDOFF.md) §9 は上流 `trk` の話）。

## 6. 用語

| 言葉 | 意味 |
| --- | --- |
| スマホ型／PC型 | 同じアプリの2つの画面構成。スマホ型＝下部ナビで1画面1役割、PC型＝従来の広い画面 |
