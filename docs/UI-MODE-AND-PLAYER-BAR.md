## 2. 設定（保存は本体の設定だけ）

| 設定 | 値 | 既定 | 効くところ |
| --- | --- | --- | --- |
| `uiMode`（画面の形） | `auto` / `desktop` / `mobile` | `auto` | `body.trk-mobile` の有無（＝下部ナビとスマホ用の見た目） |
| `playerBar`（下の再生バー） | `on` / `auto` / `off` | **`on`**（trk222 で `auto` から変更） | `#trkPlayerBar` の表示 |
| `uiScale`（拡大率） | 50 / 75 / 100 / 125（%） | `100` | PC型の画面（ステージ）と、下の再生バー |
| `fixedIconSize`（アイコンの大きさを100%で固定） | オン / オフ | **オン** | 拡大したときのアイコン（絵文字）の大きさ |
| `uiModeLock`（画面の形は常に選んだものを使う） | オン / オフ | **オン** | 右上の 📱／🖥 の選択を保存するか（❓ 謎設定） |
| `fxInLibrary`（エフェクトの欄をライブラリにも出す） | オン / オフ | オフ | スマホ型のライブラリのタブ（§8.5） |
| `playerBarPos`（バーの置き場所） | `bottom` / `above` | **`bottom`** | スマホ型のときの、バーと下部ナビの前後（§9） |
| `playerBarLock`（再生バーを隠さない） | オン / オフ | オフ | バーの ✕ を出すか（§9） |

- 保存先は既存の `core.settings`（`shadow_taiko_preferences_v2`）です。**新しい保存キーは増やしていません。**
- 検証は `core.js` の `pick()` で行うので、保存が壊れていても既定へ落ちます。
- `?reset=all`（工場出荷状態）では、どちらも既定へ戻します（`resetAllPrefs()`）。
- 設定画面の欄：⚙ → **🖥 画面と再生バー**（`#uiPanel`）。日本語・英語・中国語・韓国語の4言語。

### 2.1 画面の形（`uiMode`）

| 選んだ値 | PC（マウス） | スマホ・タブレット |
| --- | --- | --- |
| `auto` | PC型（これまでどおり） | スマホ型（下部ナビ） |
| `desktop` | PC型 | **PC型**（大きいタブレットで広く使う） |
| `mobile` | **スマホ型**（縦型のスタンド・小さい窓） | スマホ型 |

- `auto` の判定は `js/lite.js` の `TrkLite.info().mobile`（粗いポインタ／端末の UA）。判定を2か所に書かないため、シェルからは同じ窓口を呼びます。
- 切り替え方は3つ。どれも同じ `settings.uiMode` を書きます。
  1. ⚙ → 🖥 画面と再生バー → 「画面の形」
  2. 選曲画面の右上の **📱／🖥** ボタン（押すたびに 自動 → スマホ型 → PC型）
  3. 開発者向け：`Trk.mobileShell.setMode("mobile")`
- 切り替えは `enable()`／`disable()` で行い、**開き直さずに**その場で効きます。`disable()` は下部ナビ・エフェクト画面・縦向きの案内・再生画面の「ゲームモードへ」を片付け、`body.trk-mobile` と `data-trk-view` を外します。
- PC の既定（`auto`・マウスの PC）では、`body.trk-mobile` が付かず、`css/mobile-shell.css` の規則は一切当たりません。**PC の見た目は変わりません**（右上の切り替えボタンだけが増えます）。

## 3. 下の再生バー（`playerBar`）

### 3.1 出す／出さない

| 値 | 曲を選んでいないとき | 曲を選んだとき |
| --- | --- | --- |
| `on`（既定） | **出す**（曲名の欄は「曲を選ぶと、ここに曲名が出ます。」） | 出す |
| `auto` | 出さない | 出す |
| `off` | 出さない | 出さない |

どの値でも、次のあいだは**引っ込みます**（ステージと操作の邪魔をしないため）。

- ゲーム中（`core.phase` が `playing`／`paused`）
- 再生画面（メディアプレーヤー）を開いている間
- 書斎（`body.study-room-open`）
- ほかの窓（プレイリスト・「ようこそ」・インストール案内・`role="dialog" aria-modal` の重ね表示）

リザルト（`ended`）では出します（曲名を見ながら次の曲へ送れるように）。

### 3.2 部品と操作

```
[────────── 上端の細いシーク線（再生中だけ動かせる）──────────]
[ジャケット] [曲名 / 歌手]  [⏮][▶][⏭]  [0:12 / 3:45]  [🔊 音量] [⛶][✕]
```

| 部品 | 何をするか | 本体のどこを呼ぶか |
| --- | --- | --- |
| ▶／⏸ | 押した瞬間の意味は、曲名バナーの本物のボタンと同じ（選曲中はプレビュー、ゲーム中は一時停止／再開） | `#songBanner .bannerPlayBtn` をそのまま押す（**状態を二重に持たない**）。アイコンと説明もそこから写す |
| ⏮／⏭ | 前の曲／次の曲（選曲中だけ） | `Trk.library.prevSong()`／`nextSong()` → `selectSong()` |
| シーク線 | 0〜1000 を曲の長さに直して移動（再生中・一時停止中だけ） | `Trk.play.seekTo()`。ドラッグ中は追従を止め、離して0.9秒で戻す |
| 音量 | 0〜1 | `core.settings.musicVolume`・`rememberMusicVolume()`・`video.volume`・`#volume`・`saveUserPrefs()` |
| ⛶ | 再生画面を開く | `TrkMediaPlayer.open()` |
| ✕ | 「表示しない」にする | `settings.playerBar = "off"`＋保存＋通知（設定で戻せることを伝える） |

- 曲名と歌手は `Trk.library.songDisplayMeta()`（ユーザー設定 → タグ → 曲の情報の順）。曲が変わったときだけ読み直します。
- ジャケットは `Trk.library.loadSongArtwork()` の Blob を、このバー専用の `URL.createObjectURL` で表示し、**差し替え時に必ず `revokeObjectURL`** します（512 KB 超・画像以外は飾りに使わない）。
- 時間表示は `m:ss`、1時間を超えたら `h:mm:ss`。長さが分からないときは `--:--`。

### 3.3 スキン

バー専用の色は持ちません。スキンが `:root` に書く CSS 変数（`--ui-panel` `--ui-soft` `--ui-text` `--ui-muted` `--ui-border` `--ui-button-hover` `--ui-accent`）だけを使います。
`core.applySkin()` が値を書き換えると、バーも同じ色になります。検査（`tests/trk221-player-bar.test.mjs`）で「決め打ちの色（`#rrggbb`）を書かない」ことを確かめています。

### 3.4 ほかの部品と重ならないようにする

バーは `position: fixed` なので、下にある物と重なり得ます。次の4つを避けています。

| 相手 | 対策 |
| --- | --- |
| スマホの下部ナビ | ナビの上に載せる（`--trk-playerbar-offset` にナビの高さを入れ、JS が測る） |
| 選曲画面のカード | PC は `.screen` の下余白、スマホ型は `.card` の下余白にバーの高さを足す（PC は 1920×1080 の縮小率を打ち消した値を渡す） |
| 🛟 セーフモードの浮きボタン（緊急の逃げ道） | バーの上へ逃がす（`!important` でインラインの `bottom` を上書き） |
| 通知（`.plToast`） | バーの高さぶん持ち上げる |

画面の形が切り替わったときは、`MutationObserver`（`body` の class と `.trk-mobile-nav` の出入り）で測り直します。

### 3.5 入力とゲームへの干渉

- バーは**ゲーム中（`playing`／`paused`）には出ません**。キー入力・パッド・キャンバスの操作を奪いません。
- 新しい音の通り道（`new Audio()` など）は作りません。鳴らすのは本体の `video` だけです。
- 選曲中は ⏮⏭ を押せます（バナーの ◀▶ と同じ扱い）。プレイ中は無効になります。

## 9. バーの置き場所と「隠さない」（trk225）

実機の相談（2026-10-31）から。詳しい手順と確かめたことは [`PLAYER-BAR-TRK225-2026-10-31.md`](PLAYER-BAR-TRK225-2026-10-31.md)。

- **置き場所**（`settings.playerBarPos`、既定 `bottom`）：`bottom`＝画面のいちばん下・下部ナビはその上／`above`＝下部ナビの上（trk221〜trk224 までと同じ）。
  - **バーの下余白は JS**（`--trk-playerbar-offset` に `0px` かナビの高さ）／**ナビの移動は CSS**（`body.trk-playerbar-at-bottom .trk-mobile-nav { bottom: var(--trk-playerbar-h) }`）。役割を分けているので、片方を直しても段が崩れません。
  - `--trk-playerbar-h` は実寸（`getBoundingClientRect`）なので、拡大率 125%（`zoom`）でも段が重なりません。バー自身は `env(safe-area-inset-bottom)` を空け、ナビは足し直しません。
- **隠さない**（`settings.playerBarLock`、既定オフ）：オンで ✕ を出さない（`.trk-pb-actions button[hidden] { display:none !important }`）。設定の「表示しない」は本人の選択なので止めません。
- 検証：`tests/trk225-player-bar-settings.test.mjs`（22件。純粋関数・偽 DOM の実測・CSS を規則として当てた値）。
- **未確認**：実ブラウザ・実機（とくに iPhone の safe-area と、拡大率 125% のときの段）。

## 8. trk222：既定の変更・拡大率・アイコン・2択・エフェクト欄のタブ分け（2026-10-31）

利用者の要望5点への対応です。

| # | 要望 | 実装 |
| --- | --- | --- |
| 1 | 再生バーの既定を「つねに表示」に（前回聞いていた曲をそのまま出せる） | `settings.playerBar` の既定を `auto` → `on` へ。`?reset=all` でも `on` に戻る |
| 2 | 画面と再生バーに「拡大率」（100／75／50／125%、既定100%） | `settings.uiScale`（`[50,75,100,125]` だけ）。`core.applyUiScale()` と `fitStage()`。設定は ⚙ → 🖥 画面と再生バー |
| 3 | 「アイコンの大きさは100%で固定」オプション（既定オン） | `settings.fixedIconSize`。オンのとき、アイコンだけ `--trk-icon-zoom = 1/拡大率` に割り戻す |
| 4 | 右上の切り替えを3択 → **2択**（PC ↔ スマホ）に。❓ 謎設定に「常に選んだものを使う」 | `uiModeBtn` は押すたび PC ↔ スマホ。`settings.uiModeLock`（既定オン）。オフのときは「その場だけ」変えて保存しない（`sessionMode`） |
| 5 | スマホ型のライブラリにあるエフェクト関係を、エフェクトのタブへ。ライブラリにも置ける設定も | `settings.fxInLibrary`（既定オフ）。`body[data-trk-view]` と `body.trk-fx-in-library` の印で、CSS が「見せる／隠す」を切り替える（DOM は動かさない） |

### 8.1 拡大率の仕組み

ステージは 1920×1080 の「設計サイズ」を画面に合わせて縮小して見せています。拡大率は、この設計サイズを **1/拡大率** に縮めてから、その分だけ大きく描きます。

| 拡大率 | 設計サイズ | 1440×900 での倍率 | 見え方 |
| --- | --- | --- | --- |
| 100% | 1920×1080 | 0.75 | これまでどおり |
| 125% | 1536×864 | 0.9375 | 文字とボタンが 1.25 倍 |
| 75% | 2560×1440 | 0.5625 | 0.75 倍 |
| 50% | 3840×2160 | 0.375 | 0.5 倍 |

- **はみ出しません**：倍率 × 設計サイズ = 画面の短い辺に収まる（`fitStage()` が `min(innerWidth/W, innerHeight/H) × 拡大率` で描く）。1920×1080・1440×900・1366×768・1080×1920（縦型）・2560×1440・800×600 の6通り × 4段階で、はみ出さないことを確認しました。
- **ゲーム中は 100% のまま**（`playing`／`paused`）。盤面が欠けると遊べないためです。タイトル／リザルトでは拡大します。
- **スマホ型ではステージを拡大しません**（CSS が実ピクセルで並べるため）。スマホ型では下の再生バーだけが拡大します。
- 再生バーは `zoom: var(--trk-ui-zoom)` で拡大します（Chrome／Safari／Firefox 126+。古いブラウザでは 100% のまま）。バーの高さは `getBoundingClientRect()` で測り直すので、拡大しても下余白の計算がずれません。

### 8.2 アイコンの大きさを100%で固定する

拡大すると、絵文字のアイコンは線がにじみやすく、行の高さも崩れがちです。オン（既定）のときは、アイコンだけ `--trk-icon-zoom`（= 1/拡大率）で割り戻します。対象は、右上の 📱／🖥・下部ナビのアイコン・再生バーのボタンとジャケットです。オフにすると、アイコンも文字と同じ比率で大きくなります。

### 8.3 画面の形：2択と「常に選んだものを使う」

- 右上の 📱／🖥 は **押すたびに PC型 ↔ スマホ型** を入れ替えます（3択を回すより、行き先が読みやすい）。ボタンの絵柄は「いまの形」を表します。
- ❓ 謎設定「画面の形は、常に選んだものを使う」（`settings.uiModeLock`・既定オン）
  - **オン**：押した形を `settings.uiMode` に保存し、次に開いたときも同じ形で始める。
  - **オフ**：その場だけ切り替え（`sessionMode`）、保存しない。次に開いたときは端末に合わせて選び直す。
- 設定（⚙ → 🖥 画面と再生バー）の3択（自動／PC型／スマホ型）は残しています。自動はこれまでどおり端末に合わせます。

### 8.4 アイコン・文言

- 右上のボタンの説明は「画面の形を PC型 ↔ スマホ型 に入れ替える」（4言語）。

### 8.5 エフェクト欄のタブ分け（スマホ型）

スマホ型のライブラリのタブにあった次の欄を、**エフェクトのタブに集めました**。

- `#fxDock`（🎛 エフェクト：音楽エフェクトのプリセット）
- `#tvDock`（▶ TV：映像エフェクトの入口。スマホ型では元から非表示）
- `.dockMore`（🎛 くわしく（EQ・スキン・メニュー））
- `.tvMore`（📺 くわしく（設定と映像の確認））
- `#ampPanel`（🔥 TRKアンプを使う）
- `#richPanel`（✨ TRKエフェクトを使う）
- `#midiMixPanel`（🎚 TRK MIDI MIX）

**DOM は動かしていません。** `tv-dock.js`・`fx-dock.js` は列の中身を MutationObserver で並べ替えるので、外から動かすと取り合いになります。代わりに `body[data-trk-view]` と `body.trk-fx-in-library` の印だけを切り替え、`css/mobile-shell.css` が「見せる／隠す」を行います。

| タブ | 設定（🎛 ライブラリにもエフェクトの欄を出す） | 見え方 |
| --- | --- | --- |
| ライブラリ | オフ（既定） | 曲リストだけ。エフェクト欄は出さない |
| ライブラリ | オン | 曲リストの下にエフェクト欄 |
| エフェクト | どちらでも | いちばん上に「いまの曲と音のつまみ」（`#trkEffects` の鏡）、その下に本物の欄 |

- `#trkEffects`（trk220 の鏡：プリセット・EQ・映像の色調）は、エフェクトのタブの**先頭**に置きました。
- エフェクトのタブでは、曲リストの列のうち「エフェクトの欄以外」（曲リスト・検索・追加）を隠します。欄そのものの `display` は上書きしません（`#fxDock` は flex なので、`display:block` にすると見た目が崩れます）。
- PC型では何も動かしません（曲リストと曲の詳細が左右に並ぶ同じ1枚なので、分ける意味がないため）。

jsdom で実 `index.html` を開いて確かめたこと（リポジトリ外のスクリプト）：

- 既定：`uiScale=100`・`playerBar=on`・`fixedIconSize=true`・`uiModeLock=true`
- 100%：設計サイズは 1920×1080 のまま、倍率は画面なり（1440×900 → 0.75）
- 125%：設計サイズが 1536×864、倍率 0.9375、`body.trk-zoom` が付き、`--trk-icon-zoom=0.8`
- アイコン固定オフ：`--trk-icon-zoom=1`
- 50%：設計サイズ 3840×2160、倍率 0.375
- 知らない値（37）は 100% として扱う
- プレイ中は設計サイズも倍率も等倍、タイトルへ戻ると 125% に戻る
- 縦型 1080×1920 の 125%：ステージが幅いっぱいに広がり、はみ出さない
- スマホ型：ステージの幅を固定しない（`width=""`）／`--trk-ui-zoom` は渡す
- エフェクトのタブ：`#fxDock` などは列に残ったまま、`display` が `flex`／`block`（曲リストは `none`）
- ライブラリのタブ：エフェクト欄は `display:none`、設定オンで出る
- 右上のボタン：PC型（🖥）→ 押すとスマホ型（📱）→ もう一度で PC型。謎設定オフなら保存しない／オンなら `"uiMode":"mobile"` が保存される
- 1920×1080／1440×900／1366×768／1080×1920／2560×1440／800×600 × 50・75・100・125% のすべてで、ステージが画面からはみ出さない

### 8.7 これから
